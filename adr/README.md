# Architecture Decision Records (ADR)

決定そのものと、その背景・帰結を記録する。コードを読めば分かることは書かない。コードを読んでも分からないことだけを書く。

## ディレクトリ

ADR ファイルは `adr/` 直下には置かず、所有者ごとのサブディレクトリに置く。連番はディレクトリごとに振るため、ADR を指すときは番号ではなくパスで呼ぶ。

| パス | 所有 | 説明 |
|---|---|---|
| [`from-template/`](from-template/) | テンプレート元 | 同期で降ってくる。派生リポジトリでは編集しない |
| `{app name}/` | 派生リポジトリ | このリポジトリ自身の決定。テンプレート元には置かない |
